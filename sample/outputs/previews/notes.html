About this run

Applies to: Notes & Disclosures

This output set was generated from documents uploaded to a public demo. It read an offering memorandum, a trailing-twelve statement, a rent roll. 10 summary field(s) were read from the marketing document by a language model and each one is carried with the sentence it came from; any value whose sentence could not be found in the document was discarded rather than shown. Every figure on the T-12 and rent-roll tabs are computed by code from the uploaded spreadsheets, not read by a model. Each T-12 line's category was assigned from the wording of its account label, not from an account-code table, because account codes mean different things in different systems. The category chosen for every line is shown beside it on the T-12 Data tab so you can check it; lines that could not be placed confidently are excluded rather than guessed at, and are listed above. Comparable rents, demographics, competing supply and closing costs were not run: they need data sources this demo does not reach. The uploaded files were deleted as soon as they were parsed, and this output set is deleted with the rest of the run.
